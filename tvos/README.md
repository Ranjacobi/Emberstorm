# Emberstorm — Apple TV (tvOS)
By **ItRan Studios** · Ran Jacobi

Same game as iOS/Android, optimized for the big screen with Siri Remote controls.

## Controls (Siri Remote)
- **Click/Tap** the trackpad → Flip gravity
- **Swipe up/down** → Flip gravity
- **Play/Pause** button → Flip gravity
- **D-pad** → Navigate menus
- **Menu** button → Go back

## Setup
```bash
cd EmberstormTV
chmod +x setup.sh
./setup.sh
```

## Requirements
- Xcode 15+
- Apple Developer Program ($99/year — same as iOS)
- tvOS 16+ target
